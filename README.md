# Student Revision Planner

A full-stack revision planning web application built with Java, Spring Boot, MySQL, HTML, CSS and JavaScript.

The application allows users to create, view, complete and delete revision tasks. Tasks are stored persistently in a MySQL database through a Spring Boot REST API.

## Features

- Add revision tasks
- View revision tasks
- Mark tasks as completed
- Visual indicator for completed tasks
- Delete revision tasks
- Persistent MySQL storage
- REST API for task management

## Technologies

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- HTML
- CSS
- JavaScript
- Maven
- Git & GitHub

## How It Works

The application connects the frontend to the backend through a REST API:

Web Browser → JavaScript → Spring Boot REST API → JPA/Hibernate → MySQL
